## Image Specifications

### Technical Requirements
- **Format:** WebP (primary), JPEG fallback if needed
- **Color Space:** sRGB
- **Quality:** 85 (WebP), 90 (JPEG)
- **Max File Size:** 2 MB per image
- **Naming:** kebab-case, descriptive, collection-prefixed

### Dimension Standards
| Usage | Dimensions | Aspect Ratio |
|-------|------------|--------------|
| Homepage hero | 1920×1080 | 16:9 |
| Collection hero | 1920×1200 | 16:10 |
| Product hero | 1200×1600 | 3:4 (portrait) |
| Editorial/campaign | 1200×900 | 4:3 |
| Journal cards | 800×600 | 4:3 |
| About/philosophy | 1920×1080 or 1200×900 | 16:9 / 4:3 |

### Quality Control Checklist (Per Asset)
- [ ] No grid lines or contact sheet artifacts
- [ ] No clipped faces, limbs, or garment details
- [ ] No distorted anatomy (hands, feet, proportions)
- [ ] No unintended text, logos, or watermarks
- [ ] No celebrity/model likeness infringement
- [ ] Garment construction physically plausible
- [ ] Strap continuity verified
- [ ] Fabric texture realistic (not plastic/AI-smooth)
- [ ] Lighting consistent with collection direction
- [ ] Color accurate to collection palette
- [ ] Composition serves editorial purpose
- [ ] Model diversity: adult, varied ethnicity, varied build
- [ ] Alt text written and descriptive
